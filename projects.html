SciFlow-107

Slurm job-script generation agent — natural language in, validated experiment pipelines out.

natural language → ExperimentSpec → experiment matrix → sbatch → validation

Problem

Undergraduate students using HPC clusters have to understand Slurm, resource requests, and script syntax before running their very first experiment.

Approach

The LLM is responsible for what it's good at — natural-language parsing and experiment specification. A deterministic system does the rest: Cartesian product expansion, script generation, and static validation.

Robotics · Vision · 2026

RoboGame

Building an autonomous mecanum-wheel robot from scratch.

camera ↓ vision (white balance · gamma · HSV · morphology) ↓ AprilTag / block detection ↓ localization (PnP · camera-to-world) ↓ path planning ↓ motor control (STM32 · USART) ↓ robot

What I did

Led perception and control in a 5-member team: an OpenCV pipeline with white balance, gamma correction, HSV segmentation, binary morphology, geometric corner extraction and PnP-based 3D localization; camera-to-world coordinate transforms; and the USART protocol between the Python upper computer and the STM32 controller.

AI for Science · Agents · 2026

VASP Router / SkillForge

Teaching agents how to use scientific software.

scientific knowledge ↓ knowledge graph ↓ skill routing ↓ VASP workflow ↓ simulation

I explored how LLM agents can interact with domain-specific scientific software through structured skills, routing, and verification. The system maps natural-language computational-materials requests onto VASP workflows, with parameters validated against a knowledge graph derived from the VASP wiki — 933 nodes and 10,530 indexed terms, retrieved with a Python/SQLite pipeline (spelling correction, abbreviation expansion, stemming, BM25/IDF weighting, graph-based enhancement).

End-to-end execution was validated on representative tasks, including silicon and graphene calculations.

LLM · Speech · 2026

AI Mock Interviewer

A research-group interview simulator that responds in under two seconds.

ASR → streaming LLM → parallel TTS → ordered playback

Led backend development of an AI mock-interview system (FastAPI, async Python, LLMs, ASR/TTS, RAG) that simulates research-group interviews. By restructuring the speech pipeline into parallel stages with ordered playback, worst-case first-response latency dropped from ~30s to under 2s.

Designed a structured evaluation framework across 5 weighted dimensions — generating evidence, risk flags, improvement plans, follow-up questions, and machine-readable JSON reports.

Result

3rd place, USTC division — national finals (5/30 teams).
